## 📌 Overview

This is my personal interactive portfolio website showcasing my academic background, technical skills, experience, projects, and certifications. Built with a modern dark-mode aesthetic, glowing glassmorphic elements, smooth scroll reveal animations, and a fully responsive design.

---

## ✨ Features

- 🎨 **Modern Glassmorphic UI:** Sleek glass-effect cards and dark mode styling.
- 📱 **Fully Responsive:** Optimized for desktops, tablets, and mobile devices.
- ⚡ **Interactive Animations:** Dynamic particle background and smooth scroll reveal animations.
- 📂 **Project Showcase with Filtering:** Filter projects dynamically by categories (Full Stack, AI & Data, Cybersecurity).
- 📬 **Working Contact Form:** Integrated clean input form UI ready for backend or Web3Forms API.
- 🎯 **Fixed Navigation:** Auto-highlighting active links on scroll with smooth anchoring.

---

## 🛠️ Built With

* **HTML5** & **CSS3**
* **Tailwind CSS** (via CDN)
* **Vanilla JavaScript** (ES6+)
* **Font Awesome 6** (Icons)
* **Google Fonts** (*Inter* & *Space Grotesk*)
